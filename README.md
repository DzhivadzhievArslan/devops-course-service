# Учебный сервис: тема обращения в поддержку

Небольшой сервис на FastAPI с моделью машинного обучения. Получает текст обращения
в поддержку интернет-магазина и определяет его тему. На нём построен весь курс DevOps:
Git, Docker, Docker Compose, CI/CD.

Темы: `payment` (оплата), `delivery` (доставка), `refund` (возврат), `account` (аккаунт).

## Что умеет

| Метод и путь | Что делает |
|---|---|
| `POST /predict` | Определить тему: `{"text": "Списали деньги дважды"}` → тема, уверенность, версия модели |
| `GET /predictions` | Последние предсказания, новые сверху (`?limit=20`) |
| `GET /health` | Процесс жив (база и модель не проверяются) |
| `GET /ready` | Сервис готов: база отвечает и модель загружена. Если нет — код 503 |
| `GET /version` | Версия сервиса, версия модели и её точность |

Каждое предсказание записывается в базу вместе с версией модели.
Документация API и кнопки для запросов — http://127.0.0.1:8000/docs.

## Модель

- Данные — `data/tickets.csv`: 160 обращений, по 40 на тему.
- Модель — TF-IDF по буквенным n-граммам и логистическая регрессия (scikit-learn).
  Обучается за секунды, файл модели — около 220 КБ.
- 25 % данных откладываются: на них модель не учится, по ним считается точность.
- Версия модели — отпечаток данных и параметров обучения: те же данные дают ту же версию.
- Тест `tests/test_quality.py` падает, если точность ниже 0,85.

Файл модели загружается через `joblib` (то есть `pickle`). Загружать можно только модель,
собранную своим конвейером: чужой файл модели может выполнить любой код.

## Параметры

| Переменная | По умолчанию | Зачем |
|---|---|---|
| `DATABASE_URL` | `sqlite:///./app.db` | Адрес базы. Для PostgreSQL: `postgresql+psycopg://app:secret@db:5432/app` |
| `MODEL_PATH` | `model/model.joblib` | Файл модели |
| `APP_VERSION` | `dev` | Версия сервиса в `/version` |

## Запуск на своём компьютере

Нужен Python 3.12 или новее.

```bash
python -m venv .venv
# Windows (Git Bash):  source .venv/Scripts/activate
# macOS и Linux:       source .venv/bin/activate
pip install -r requirements-dev.txt
python -m app.train          # обучить модель → model/model.joblib
uvicorn app.main:app --reload
```

Без шага `python -m app.train` сервис запустится, но `/ready` и `/predict` ответят 503.

## Проверки

```bash
ruff check .            # стиль и типовые ошибки
ruff format --check .   # форматирование
pytest                  # тесты и проверка качества модели
```

Тесты обучают модель сами и работают с базой SQLite в памяти: PostgreSQL и файл модели для них не нужны.
